# Dotfiles

I need a directory to run claude from when it works on my dotfiles, and this is it.  Technically
speaking, I keep my dotfiles living right at $HOME and backed by [a git repo](~/.dotfiles.git).  But they
live scattered throughout my tree, wherever important configuration files might live.

I generally prefer to commit my own changes to this repo.

Please be aware that my system configuration is used on multiple different machines and both macs and
linux boxes.  Some of those systems have additional local configuration that's only used there.
